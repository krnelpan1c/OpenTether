Why OpenTether

Tethering that works for every app

Proxy-based tethering only helps the browser. OpenTether gives your computer a real network connection through your phone.

sports_esports

Games, Steam and voice chat

A virtual network adapter carries all traffic: TCP, UDP, DNS, IPv6 and QUIC. Apps work without any proxy settings or a VPN.

cell_tower

Uses the phone's own connection

OpenTether doesn't use Android's hotspot. The app opens connections on the phone for your computer, just like any other app uses mobile data.

bolt

Fast over USB and Wi-Fi Direct

Early tests reached about 280 Mbit/s over a USB 2.0 cable and up to 600 Mbit/s over Wi-Fi Direct.

devices

Phones, tablets and consoles too

Devices that can't run the desktop client connect through a built-in HTTP and SOCKS5 proxy on the phone's Wi-Fi Direct network.

lock

Encrypted and paired

Traffic between phone and computer is encrypted with QUIC and TLS 1.3. Wi-Fi Direct pairing uses a QR code shown on the phone.

code

Free and open source

Licensed under the GNU GPL v3.0. No ads, accounts or time limits, and no root needed. The code for the Android app and desktop client is on GitHub.

The Steam problem

Why some apps fail with other tethering apps

Steam, online games and voice chat often fail with proxy-based tethering, leaving a VPN as the usual workaround. OpenTether is built so they work directly.

cancelProxy-based tethering

  • cancelOnly carries TCP, so UDP traffic for games, Steam and voice chat is dropped.
  • cancelOnly apps that read the system proxy settings use it; many games and launchers don't.
  • cancelWindows can report "No Internet", so some apps switch to offline mode.

  • check_circleCarries every packet, including UDP, DNS, IPv6 and QUIC.
  • check_circleA virtual network adapter means every app is covered, with nothing to configure.
  • check_circleWindows sees a normal internet connection.

How it works

From your apps to the mobile network

The desktop client and the phone app work together over one encrypted connection.

  1. computer

    1. Your computer

    A virtual network adapter collects all traffic from your apps.

  2. usb

    2. USB or Wi-Fi Direct

    Traffic travels to the phone over an encrypted QUIC connection.

  3. phone_android

    3. The OpenTether app

    The app opens matching connections on the phone's mobile data.

  4. public

    4. The internet

    Replies come back the same way, to the app that asked for them.

Setup

Connect in a minute

Install the OpenTether app on your phone and the desktop client on your computer, then choose how to connect.

usb

USB

  1. Turn on USB debugging in Developer options, then turn on USB in the app.
  2. Connect the phone with a cable.
  3. On the computer, run as administrator: opentether usb
wifi_tethering

Wi-Fi Direct

  1. Turn on Wi-Fi Direct in the app. A QR code and pairing link appear.
  2. On the computer, run: opentether wifi --pair "<link>"
  3. The computer joins the phone's network by itself. Next time, just run opentether wifi.
videogame_asset

Other devices

  1. Turn on Wi-Fi Direct and Devices without the app in the app.
  2. Join the phone's DIRECT-OT-… network on the other device.
  3. Set its proxy to 192.168.49.1 port 8080.

Only apps that honour proxy settings work for other devices. Computers should use the desktop client for full support.

Requirements

What you need

PhoneAndroid 10 or newer. No root needed. USB mode needs USB debugging; Wi-Fi Direct needs Wi-Fi turned on.
WindowsWindows 10 or 11, run as administrator. The virtual adapter driver (Wintun) is included.
LinuxRun with sudo. NetworkManager lets the client join Wi-Fi Direct automatically.
macOSRun with sudo. The client isn't signed yet, so clear the quarantine flag the first time.
USB modeadb (Android platform-tools) on the computer.

FAQ

Questions and answers

Is OpenTether free?

Yes. OpenTether is free and open source under the GNU GPL v3.0, with no ads, accounts or time limits. The code is on GitHub.

Why do Steam and some games fail with PdaNet, and does OpenTether fix it?

Tethering apps that work through a proxy only carry TCP connections from apps that respect proxy settings. Steam, online games and voice chat rely on UDP and often ignore proxy settings, so they fail unless you add a VPN.

OpenTether's desktop client creates a virtual network adapter that sends every packet, including UDP, DNS and IPv6, through the phone, so these apps don't need a workaround.

Does OpenTether use my phone's hotspot?

No. OpenTether doesn't use Android's built-in hotspot or USB tethering. The app opens ordinary network connections on the phone on the computer's behalf, the same way any other app uses mobile data.

You are responsible for following your carrier's terms of service.

Do I need to root my phone?

No. OpenTether works on Android 10 and newer without root. USB mode uses adb, so it needs USB debugging turned on in Developer options. Wi-Fi Direct mode needs nothing extra.

Is the connection between my phone and computer secure?

Yes. Phone and computer talk over QUIC with TLS 1.3 encryption. The computer pins the phone's certificate, and Wi-Fi Direct connections also need a pairing code from a QR code shown on the phone.

Can phones, tablets or game consoles use OpenTether?

Yes, through proxy mode. Devices that can't run the desktop client join the phone's Wi-Fi Direct network and set its HTTP or SOCKS5 proxy, or proxy auto-config, in their network settings. Only apps that honour proxy settings work in this mode.

Does OpenTether work with iPhone?

No. The phone app is for Android 10 and newer. The desktop client runs on Windows, Linux and macOS.
